MovieCatalog

Этап 1: Проектирование и защита идеи

Проблема

  • Сложно находить персонализированные подборки фильмов
  • Нет единого места для сохранения любимых фильмов
  • Разрозненные источники информации о кино

Решение

  • Удобный каталог фильмов с поиском, детальной информацией и списком избранного
  • Интуитивный интерфейс
  • Локальное хранение избранного
  • Быстрый доступ к информации

Ключевой функционал

  • Просмотр популярных фильмов
  • Поиск по названию
  • Детальная страница фильма
  • Список избранного

Преимущества

Кастомизация

Лёгкая настройка рекомендаций

UI/UX

Минималистичный адаптивный интерфейс

Офлайн-доступ

Избранное доступно без интернета

Сценарий 1: Поиск фильма

  1. Пользователь открывает главную страницу
  2. Видит популярные фильмы
  3. Использует поиск по названию
  4. Открывает страницу выбранного фильма

Сценарий 2: Работа с избранным

  1. Пользователь на странице фильма
  2. Добавляет фильм в избранное
  3. Переходит в раздел "Избранное"
  4. Просматривает сохранённые фильмы

Сценарий 3: Фильтрация

  1. Пользователь фильтрует результаты
  2. Выбирает жанр или год
  3. Кликает на интересный фильм
  4. Делится ссылкой с друзьями

API: Обзор

Интеграция с TMDB API + собственные endpoint'ы

  • Популярные фильмы
  • Поиск по названию
  • Детали фильма

API: Endpoints

  • GET /movie/popular?page={n} (TMDB)
  • GET /search/movie?query={q}&page={n} (TMDB)
  • GET /movie/{id} (TMDB)
  • GET /api/movies/popular?page={n} (proxy / локальный endpoint)
  • GET /api/movies/search?q={q}&page={n}
  • GET /api/movies/{id}
  • GET /api/favorites
  • POST /api/favorites { "movieId": 123 }
  • DELETE /api/favorites/{movieId}
  • TMDB токен хранится в окружении (SERVER_TMDB_API_KEY)
